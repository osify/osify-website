# ask.osify.com — redirects only

Generated by `scripts/build-ask-redirects.mjs` in the osify-website repo.
Do not edit by hand; regenerate and republish instead.

Every `/qa/<id>` URL forwards to its article on https://osify.com.
Everything else forwards to https://osify.com/archive/.

## Deploying

Push this directory to its own GitHub repository with Pages enabled
(branch `main`, folder `/`), then point a DNS CNAME record for
`ask.osify.com` at `<owner>.github.io`.
