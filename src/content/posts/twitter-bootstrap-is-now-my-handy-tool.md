Now Twitter Bootstrap has reached version 2.2.2. It is now including for all of my projects and my recommendation for those who want to have a nice UI view and easy handy client design coding, you should consider it now.

You can find twitter bootstrap in different project:

- Official Twitter Bootstrap: [GitHub](http://twitter.github.com/bootstrap/)
- Applied: [Struts2 Bootstrap](http://code.google.com/p/struts2-bootstrap/)
- Applied: [GWT Bootstrap](https://github.com/gwtbootstrap)
- and more others…

Beside the nice UI, it’s also providing some free icons and you can integrate more icon via [FontAwesome](http://fortawesome.github.com/Font-Awesome/) or [FontAwesomeMore](https://github.com/gregoryloucas/Font-Awesome-More).

And now you can find many templates are designed using Bootstrap as well.

Are you using it now?
