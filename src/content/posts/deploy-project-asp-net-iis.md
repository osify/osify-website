#### **I.          សេចក្តីផ្តើម**

នៅក្នុងមេរៀននេះ ខ្ញុំនឹងបង្ហាញអ្នកទាំងអស់គ្នាអំពីរបៀប Deploy Project ASP.NET ក្នុង IIS។ សូមមើលនូវការអនុវត្តន៍ខាងក្រោមនេះ៖

#### **II.        បើក Project ដែលចង់ Publish**

សូមធ្វើការបើក Project ណាមួយដែលលោកអ្នកចង់ធ្វើការ Deploy ទៅក្នុង IIS។ ខាងក្រោមនេះគឺជា Project របស់ខ្ញុំដែលចង់ធ្វើការ Deploy។
