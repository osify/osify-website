Recently when I open skype, it always stuck and could not connect to the server.

Skype has problem now!

People may notify this as a very critical issue because of since Microsoft bought skype for $8.5 billion recently.

If skype keeps having problem and not quickly resolve it, Microsoft will loss a lot on buying skype.

I think most people uses and loves Skype, among them don’t like Microsoft as well so with the recent problem, it can impact one Skype population as well. Let’s see!

> Update 3: (07/05/2011)
>
> Today’s problems have stabilised, and recovery is ongoing. Skype should return to normal soon.
>
> If you were disconnected from Skype earlier, you shouldn’t need to manually sign back in to Skype – it should reconnect automatically when it’s able to do so.
>
> We apologise for the disruption to your conversations.
>
