WordPress 3.4, named for guitarist Grant Green released yesterday (13/06). There are a hug changes and many things claimed to be improved with this version. But first before upgrading be aware to read [the codex of version 3.4.](http://codex.wordpress.org/Version_3.4)

Some highlight of the version are:

- **Enhanced theme control**
  - Customize theme options before activating a new theme using Theme Customizer
  - Use Theme Previewer to customize current theme without changing the front-end design

- **Custom Headers**
  - Improved [Custom Headers](http://codex.wordpress.org/Custom_Headers "Custom Headers") with flexible sizes
  - Selecting [Custom Header](http://codex.wordpress.org/Custom_Headers "Custom Headers") Images and [Custom Background](http://codex.wordpress.org/Custom_Backgrounds "Custom Backgrounds") Images from [Media Library Screen](http://codex.wordpress.org/Media_Library_Screen "Media Library Screen")

- **Media improvements**
  - Support HTML in image captions

- **Under the Hood improvements**
  - Improvements in WordPress internationalization and localization ([more info](http://wppolyglots.wordpress.com/important-changes-for-wordpress-3-4/ "http://wppolyglots.wordpress.com/important-changes-for-wordpress-3-4/"))
  - Different split in translation POT files for faster translations
  - Codex XML-RPC information update accessed via [XML-RPC_WordPress_API](http://codex.wordpress.org/XML-RPC_WordPress_API "XML-RPC WordPress API")
  - [WP_Query](http://codex.wordpress.org/Class_Reference/WP_Query "Class Reference/WP Query") improvements

Just a snap, please have a look at WordPress.org for detail.

I haven’t upgrading or have a look in detail what will change on my sites yet, will do it soon.
