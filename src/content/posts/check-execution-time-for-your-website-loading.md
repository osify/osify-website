I found an interesting tool (<http://tools.pingdom.com>) in order to check performance of the site loading page, it works at client content as HTML, javascript, CSS or image may requires much loading time, so this tool may help you.

Any way, we still need another tool to track performance at dynamic content part, with db execution time etc.

Demo: Check [http://osify.com](http://tools.pingdom.com/?url=http://osify.com&treeview=0&column=loadtime&order=1&type=0&save=true) loading time as well.
