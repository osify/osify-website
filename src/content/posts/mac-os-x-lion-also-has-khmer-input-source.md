បន្ទាប់​ពី​យើង​ខ្ញុំ​បាន​តំឡើង​ Mac OS  X Lion រួច​មក​យើង​ឃើញ​ថា​ឥឡូវ​នេះគេ​បាន​បញ្ចូល​ក្តារចុច​ និង​ភាសាខ្មែរ​ចូល​ក្នុង​ប្រព័ន្ធ​ដំណើរ​ការ​របស់​វា​តែ​ម្តង។ ដូច្នេះ​ភាសា​ខ្មែរ​របស់​យើង​ពិតជា​កំពុង​តែ​ទទួល​ស្គាល់​ដោយ​សំនាក់​ក្រុមហ៊ុន​កុំព្យូទ័រ​ហើយ​។ បំដូង​គេ​នោះ​គឺ​ក្រុមហ៊ុន Microsoft ដែល​បាន​ដាក់​បញ្ចូល​ភាសា​ខ្មែរ​ចូល​នៅ​ក្នុង Windows 7 របស់​ខ្លួន​ បន្ទាប់​មក​នេះ​គឺ​ក្រុមហ៊ុន​ Apple ដែល​ទើប​តែ​បានធ្វើ​ដូច​គ្នា​ផងដែរ។

សូម​មើល​របៀប​កំណត់​អក្សរ​ខ្មែរ​នៅ​ក្នុង​ Mac OS X Lion ដូច​ខាង​ក្រោមៈ

1. ចុច​លើ​រូប​ផ្លែប៉ោម​នៅ​ខាង​ឆ្វេង​ដៃ​ផ្នែក​ខាង​លើ

![](https://i1.wp.com/ktop.com.kh/wp-content/uploads/2011/07/Apple.jpg?resize=337%2C299 "Khmer")

2. ស្វែង​រក​និង​ចុច​លើ​ System Preference

3. ចុច​លើ​ Language & Text

![](https://i1.wp.com/ktop.com.kh/wp-content/uploads/2011/07/Apple-1.jpg?resize=580%2C493 "Khmer 1")

4. ជ្រើសរើស​យក Input Source

![](https://i2.wp.com/ktop.com.kh/wp-content/uploads/2011/07/apple-2.jpg?resize=580%2C508 "khmer2")

5. ទាញ​ mouse ចុះ​មក​ក្រោម​ស្វែង​រក​ពាក្យថា​ Khmer

6. និង​គូស​សញ្ញា​ Tick នៅ​ក្នុង​ប្រអប់​ Khmer នោះ​លោក​អ្នក​នឹង​ឃើញ​រូប​ទង់​ជាតិ​នៅ​ខាង​ស្តាំដៃ​ផ្នែក​ខាង​លើ​ ដែល​លោកអ្នក​អាច​ក្តារ​ចុច​បាន​​

![](https://i1.wp.com/ktop.com.kh/wp-content/uploads/2011/07/apple-3.jpg?resize=297%2C208 "khmer3")

After updating to Mac OS X Lion, we found that it also has Khmer input source originally. This means that our language is now recognized by computer OS companies. Those two giant companies are Microsoft and Apple.

You can add Khmer input source as follow:

1. Click on Apple icon on the above left hand side

![](https://i1.wp.com/ktop.com.kh/wp-content/uploads/2011/07/Apple.jpg?resize=337%2C299 "Khmer")

2. Choose system preference

3. Click on Language & Text

![](https://i1.wp.com/ktop.com.kh/wp-content/uploads/2011/07/Apple-1.jpg?resize=580%2C493 "Khmer 1")

4. Press on Input Source and scroll down to find “Khmer”

![](https://i2.wp.com/ktop.com.kh/wp-content/uploads/2011/07/apple-2.jpg?resize=580%2C508 "Khmer2")

5. Tick in the box then you will see the flag on the above right hand side

![](https://i1.wp.com/ktop.com.kh/wp-content/uploads/2011/07/apple-3.jpg?resize=297%2C208 "khmer 3")

6. You can enjoy using Khmer keyboard and font on Mac OS X Lion
