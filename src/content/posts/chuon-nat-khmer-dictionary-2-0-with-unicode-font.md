Let’s try to distribute Khmer Dictionary to help all Khmer or people get to know Khmer language enjoy using our right dictionary than some dictionary that wrote wrong Khmer word…

Here, it is [Chuon Nat Khmer Dictionary (Khmer to Khmer) 2.0 to download](http://www.snapdrive.net/files/583222/Software/KhmerDictionary2-ChuonNat.zip).
The dictionary using Khmer Unicode so please download [Khmer Unicode 2.0](http://www.snapdrive.net/files/583222/Software/KhmerUnicode2.0.0.zip).
The dictionary contains also the short explanation about Khmer Language Grammar.

Thanks to [Buddhist Institute of Cambodia](http://www.budinst.gov.kh/?q=node/314).
