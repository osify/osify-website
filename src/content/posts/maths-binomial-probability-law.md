Each trial has only two possible outcomes (Hence the name…)

- Must be two discrete variables
- n identical trials
- Each trial is independent of other trials
- P(success) = p, P(failure) = q = 1-p
- p and q remain constant throughout the trials
- In n trials, x successes are possible, where 0 £ x £ n
