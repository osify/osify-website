According to the [global state counter](http://gs.statcounter.com/#browser-ww-weekly-201120-201220) via [TheNextWeb](http://thenextweb.com/google/2012/05/21/google-chrome-overtakes-internet-explorer-as-the-webs-most-used-browser/), Google Chrome becomes a most used web browser in the world which is measured by the statistic data from 2011 to May of 2012 if comparing to Microsoft Internet Explorer (IE), Firefox, Sofari, Opera and others.

[![Global State Counter, Top 5 browsers](/media/5b/5b4248c4b595-statcounter.webp "statcounter-520x273")](/media/5b/5b4248c4b595-statcounter.webp)

Global State Counter, Top 5 browsers

Google Chrome has come on leaps and bounds since launching in 2008. Even myself start to use Chrome more often; I used Firefox for many years but its performance is becoming slower and slower. Currently I keep using both Firefox and Chrome to see when I can do all as Firefox (of course, it does ~ just my awareness), I will fully switch to Chrome if Firefox doesn’t give me a better performance.

[![Global State Counter, Top 5 browsers](/media/e8/e875a7b4d3a4-statcounter-may1.webp "statcounter-may1-520x307")](/media/e8/e875a7b4d3a4-statcounter-may1.webp)

Global State Counter, Top 5 browsers

In any how, the statistic is just one source of data, people in Cambodia might keep using Firefox or IE since we have recently and officially the Firefox in Khmer language translated by [Aurora Group](http://osify.com/2012/03/firefox-12-has-khmer-localized-thanks-to-firefox-aurora-khmer-group/#.T78bzVJJp8E) and a very good cooperation between ICT community in Cambodia and Mozilla which you can find information [here](http://blog.mozilla.org/gen/category/cambodia/); And IE is coming together with Microsoft Windows. But Google Chrome, we don’t have any officially link together yet, only some people [made localization](http://productforums.google.com/forum/#!category-topic/chrome/give-feature-feedback-and-suggestions/NERbelL7D48) on their own and share among community and it is having some bugs with Khmer Unicode as well which I used to state in [my post in July 2011](http://productforums.google.com/forum/#!category-topic/chrome/give-feature-feedback-and-suggestions/NERbelL7D48).

However for me, a light weight browser, we can consider Google Chrome for today.

**How do you think? Which browser are you using?**
