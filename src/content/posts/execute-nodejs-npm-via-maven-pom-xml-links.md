<http://kielczewski.eu/2014/04/building-frontend-as-a-part-of-maven-build-lifecycle/>

2. Setting up Maven to use Grunt/NodeJS
<http://blog.trifork.com/2014/10/07/setting-up-maven-to-use-gruntnodejs/>

3. Using npm, bower, and grunt with Maven
