**I.          ជំហានទី១៖ សរសេរកូដចូល**

![](/media/21/21583ea5a4ab-1.webp)

###### **II.          ជំហានទី២៖ ពណ៌នាអំពីកូដ**

ត្រង់បន្ទាត់ទី៖

- 1. ត្រូវ include header file <iostream> ដើម្បីអាចអោយយើងសរសេរកូដ C++ បាន
- 3. ត្រូវធ្វើការ import namespace std; ចូលដើម្បីអាចអោយយើងប្រើប្រាស់ keyword របស់ c++ បាន។ std មកពីពាក្យថា standard ករណីដែលយើងមិនបាន import វាចូលទេ យើងអាចសរសេរកូដ C++ បាន តាមរយៈ ការហៅ std មកប្រើ។ ឧទាហរណ៍ **std::cout<<”Hello world”;** តែប្រសិនបើយើង import វានៅខាងលើរួច យើងគ្រាន់តែសរសេរធម្មតាបានហើយ **cout<<”Hello world”;**។
- 5. Function main សម្រាប់ដំណើរការកូដរបស់យើងមុនគេបង្អស់។
- 8. ការប្រកាសអថេរ (variable) n ជាប្រភេទទិន្នន័យ integer សម្រាប់ផ្ទុកតម្លៃលេខនៅពេលដែល user ធ្វើការបញ្ចូលទៅអោយ array size (ប្រវែងរបស់ array)។
- 10. ជា display សម្រាប់បង្ហាញប្រាប់ user ដើម្បីធ្វើការបញ្ចូលទិន្នន័យលេខរបស់ array size
- 11. ជាតម្លៃលេខដែលត្រូវបញ្ចូលទៅអោយអថេរ n តាមរយៈ keyboard input
- 13. ការប្រកាស array ដែលមានធាតុ n តាមរយៈចំនួនដែលយើងបានបញ្ចូលពីតម្លៃ n ខាងលើ។ ឧទាហរណ៍ប្រសិនបើយើងបញ្ចូល១០តម្លៃ នោះ array របស់យើងនឹងត្រូវចាប់យកតម្លៃនៃ arrayចំនួន 10 ដែរ។
- 15. គឺជាការ loopនូវ ចំនួនដេងនៃ array ដែលយើងត្រូវបញ្ចូលធាតុនោះ
- 17. ជាការបង្ហាញ ដើម្បីអោយយើងធ្វើការបញ្ចូលនូវតម្លៃធាតុរបស់ array
- 18. ជាចំនួនដែលត្រូវបញ្ចូលតម្លៃរបស់ធាតុនៃ array និមួយៗរហូតដល់កំណត់របស់ array size
- 21. ជាការបង្ហាញនូវ message នៅលើ screen អំពីលទ្ធផលដែលត្រូវបញ្ចេញប្រាប់ user
- 22. គឺជាការ loop រហូតដល់ចំនួន n ដែលយើងបានបញ្ចូលពីខាងលើ

24. គឺជាការបង្ហាញនូវលទ្ធផលដែលបញ្ចេញពាក្យថា index[0]  ដែលរួមមាននូវតម្លៃនៃធាតុ array។ ឧទាហរណ៍ index[0]=12
