By default, Mac OS X does not display any icon on the desktop. Not even the internal hard disk. In this article, I will be showing how simply you can display Hard Disks on the Mac OS X desktop.

As you can see, not a single icon is displayed on the Mac OS X desktop photo above.

To display hard disks icons on the desktop, follow the below steps:

1. Launch Finder from the Dock

![](https://i2.wp.com/ktop.com.kh/wp-content/uploads/2011/09/finder-dock.png?resize=279%2C104 "finder")

2. Using the Menu bar, click on Finder then click on **Preferences…**

**![](https://i0.wp.com/ktop.com.kh/wp-content/uploads/2011/09/finder-preference.png?resize=350%2C235 "finder preference")**

**3. Under the General tab, you can see that only External disks and CDs, DVDs and iPods are selected by default to be displayed on the desktop. What about the internal hard disk for example ? to display the hard disk icon on the desktop, select the checkbox beside Hard disks.**

![](https://i0.wp.com/ktop.com.kh/wp-content/uploads/2011/09/hard_disks_enabled.png?resize=355%2C448 "Mac os x")

If you want to hide the hard disk icon from the desktop, then all what you have to do is to deselect the checkbox beside Hard disks and the icon will be removed from the desktop.

![](https://i2.wp.com/ktop.com.kh/wp-content/uploads/2011/09/Screen-Shot-2011-09-18-at-6.31.57-PM.png?resize=580%2C326 "mac")
