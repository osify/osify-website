As an IT student or professional, you might seek for what are the tech groups that you can be a part in Cambodia.

Here I would list out the group I have known here:

## Barcam Phnom Penh

- About Conference in Technologies & Business
- **Website**: <http://barcampphnompenh.org>
- **Forum**: [Google Group](https://groups.google.com/forum/?fromgroups#!forum/barcampphnompenh)
- **Activities**: Active, annually event happen, more than 900 topics in the forum until now; The source of other tech-group happen in Cambodia

## Share Vision Team / DevCamp

- A non-profit voluntary team, found during mini Barcamp in August 2009
- **Website**: <http://www.sharevisionteam.org/>
- **Forum**: [Google Group](http://groups.google.com/group/sharevisionteam)
- **Activities**: Active running Monthly DevCamp, Discussion forum reached more than 300 topics

## Pailin Group – Ruby Language Group

- Pailin is a place for Rubyists in Cambodia. People who are writing Ruby programming codes and/or developing RubyOnRails web applications
- **Website**: <http://pailin.github.com/>
- **Forum**: [Google Group](https://groups.google.com/forum/#!forum/pailin)
- **Activities**: Promoting Ruby programming, more than 70 topics discussion in the forum

## Cambodia PHP Developer Group – CamPdg

- PHP Developer Sharing
- **Website**: N/A
- **Forum**: [Google Group](https://groups.google.com/forum/?fromgroups#!forum/campdg)
- **Activities**: Discussion about various issue of PHP programming, the group not so active but so many PHP developers in Cambodia and there are more than 80 topics in the forum now

## PyKhmer – Python User Group in Cambodia

- Python programmers group
- **Website**: <http://pykhmer.wordpress.com/>
- **Forum**: N/A
- **Activities**: Promoting Python programming, currently I haven’t seen any activity of this group but of course, python developers are in Cambodia, hope this group is alive again.

## WordPress Cambodia – Talk & Share about WordPress CMS

- Who are using WordPress as a user or developer of Theme, Plugin in Cambodia
- **Website**: N/A
- **Forum**: [Google Group](https://groups.google.com/forum/?fromgroups#!forum/wordpresskhmer)
- **Activities**: I think it just started, already 12 topics in the forum now

## Joomla User Group Cambodia – Talk & Share about Joomla CMS

- Joomla User or Developer in Cambodia
- **Website**: [http://khmerjoomla.org](http://khmerjoomla.org/)
- **Forum**: [Google Group](https://groups.google.com/forum/?fromgroups#!forum/jugcam)
- **Activities**: Active, more than 750 topics in the forum

## Cambodia JAVA Developer Group

- New group, just created in September 2012 but there are many Java developers in Cambodia as well
- **Website**: <http://javacambodia.blogspot.com>
- **Forum**: [Google Group](https://groups.google.com/forum/#!forum/javacambodia)
- **Activities**: New, no activity yet, only 6 topics until today

I might miss a lot of groups but of course, I will keep update the list if any, please let me know in comment or send me a message if I have to add up some groups to mention. Above list are the group I cross around in Cambodia. We do hope to have more active groups that helps to promote developers in Cambodia.

Be a part of a group you want now!
