**មាតិកា**

XIII.Traversing DOM Elements ដោយប្រើប្រាស់ jQuery

នៅក្នុង jQuery library រួមបញ្ចូលនូវ methods ផ្សេងៗគ្នា សម្រាប់ដើម្បីធ្វើការឆ្លងកាត់នូវ DOM elements ដែលស្ថិតនៅក្នុងរចនាសម្ព័ន្ធ DOM។ ក្នុងតារាងខាងក្រោមបង្ហាញអំពី jQuery methods សម្រាប់ធ្វើការទៅ Traversing DOM elements

![](/media/b5/b5cc17f8adc6-1.webp)

រូបភាពខាងក្រោមបង្ហាញអំពីវិធីប្រើប្រាស់ jQuery traversing methods ដើម្បីទទួលយកនូវ DOM Elements

![](/media/ae/ae847714d7ea-2.webp)

1. **jQuery each() Method**

jQuery each() method គឺត្រូវបានគេប្រើទៅលើ element ដែលជាក់លាក់ (ត្រូវបានបញ្ជាក់ដោយ selector) ហើយនិង execute callback function សម្រាប់ element និមួយៗ។

**រូបមន្ត**

```
$('selector expression').each(callback function);
```

**លទ្ធផល**

![](/media/46/46d2ef772259-4.webp)

1. **jQuery children() Method**

jQuery children() method គឺត្រូវបានគេប្រើដើម្បីget នូវ child element នៃ element ដែលបានបញ្ជាក់ដោយប្រើប្រាស់នូវ selector expression។

**រូបមន្ត**

```
$('selector expression').children();
```

1. **jQuery find() Method**

jQuery find() method គឺត្រូវបានគេប្រើដើម្បី return រាល់ child elements ដែលត្រូវនឹងវា។

**រូបមន្ត**

```
$('selector expression').find('selector expression to find child elements');
```

1. **jQuery next() Method**

jQuery next() method គឺត្រូវបានគេប្រើដើម្បី ទទួលនូវ element ដែលដូចគ្នាភ្លាមៗ។

**រូបមន្ត**

```
$('selector expression').next();
```

jQuery parent() method គឺត្រូវបានគេប្រើដើម្បី ទទួលនូវ parent element។

**រូបមន្ត**


1. **jQuery siblings() Method**

jQuery siblings() method គឺត្រូវបានគេប្រើដើម្បី ទទួលយករាល់នូវ siblingsទាំងអស់នៃ element។

**រូបមន្ត**

```
$('selector expression').siblings();
```
