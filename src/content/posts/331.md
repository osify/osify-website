**32-bit** និង**64-bit** គឺ​ជា​កុំព្យូទ័រ architecture  (ធាតុ​​ដែល​អាច​​​​បង្កើត​ជា​​ប្រព័ន្ធ​កុំព្យូទ័រ​មួយ​)​ ដែល​ផ្ដោត​សំខាន់​ទៅ​លើ​ប្រវែង (​ល្បឿន​បញ្ជូន​ទិន្នន័យ) និង​ទំហំ​នៃ​ប្រភេទ​ទិន្នន័យ​  និង​ទីតាំង addresses ដែល​អាច​បម្រុង​ទុក ។ និយាយ​ដល់ 32-64bit ត្រូវ​គិត​ទៅ​លើ​ប្រព័ន្ធ​កុំព្យូទ័រ​ដែល​ត្រូវ​មាន ៣ផ្នែក​យ៉ាង​សំខាន់​ចាំបាច់​​​គឺ៖ ១. Hardware ២. ប្រព័ន្ធ​ប្រតិបត្តិការ (OS) និង​ទី៣ គឺ កម្មវិធី​ (Application) សម្រាប់​ប្រើប្រាស់​ជា​មួយ​ ឱ្យ​ដំណើរការ​បាន ។

![](https://i0.wp.com/news.sabay.com.kh/wp-content/uploads/2013/08/32-Bit-and-64-Bit.jpg?resize=423%2C300 "32-Bit-and-64-Bit")

គេ​និយាយ​ថា 32-bit និង 64-bit គឺ​សំដៅ​លើ​របៀប​នៃ​ការ​គ្រប់​គ្រង​ព័ត៌មាន​ (handle information)។ កំណែ 64-bit អាច​ធ្វើ​ឱ្យ​សមត្ថភាព​ដំណើរការ​របស់ Random Access Memory (RAM) ប្រើ​អស់​លទ្ធភាព និង​ទំហំ​ធំ​ជាង ហើយ​ដំណើរការ​បាន​ល្អ​ប្រសើរ​ជាង​ប្រព័ន្ធ 32-bit។ កម្មវិធី​ទំនើបៗ​មួយ​ចំនួន​សព្វ​ថ្ងៃ​ត្រូវ​ការ​ប្រើ RAM ទំហំ​ធំ​ជាង 4GB ដើម្បី​បំពេញ​កិច្ចការ​របស់​គេ​បាន​រលូន។

![](https://i1.wp.com/news.sabay.com.kh/wp-content/uploads/2013/08/32-bit-64-bit-explained-442-322.jpg?resize=442%2C322 "32-bit-64-bit-explained-442-322")

ចាប់​តាំង​ពី​ឆ្នាំ ១៩៩៥ នៅ​ពេល Windows 95 ត្រូវ​បាន​ណែនាំ​ដាក់​ឱ្យ​ប្រើប្រាស់ គឺ​គាំទ្រ​បាន​តែ​ពពូក​កម្មវិធី 32-bit ប៉ុណ្ណោះ ដោយ​សារ​កូដ Software និង Operating System សុទ្ធតែ​សរសេរ​ឡើង​ដើម្បី​បំពេញ​នៅ​លើ 32-bit។ ដំណាក់កាល​ក្នុង​ការ​បង្កើត​ប្រព័ន្ធ 64-bit ដំបូង​ឡើយ​ត្រូវ​គិត​ដល់ Processor (ឬ​ដែល​ត្រូវ​គេ​ហៅ​ថា CPU)​ បន្ទាប់​មក​គឺ Operating System (OS) មាន​សមត្ថភាព​ដំណើរការ​ខ្ពស់ ដើម្បី​ប្រើ​ឱ្យ​ស័ក្ដិសម​ជា​មួយ​កម្មវិធី​ធំៗ និង Application។ មាន​ន័យ​ថា ដំបូង​ឌីហ្សាញ hardware សិន រួច​បង្កើត OS ដែល​ប្រើ​បាន​ជា​មួយ Hardware 64-bit នឹង​ចុង​ក្រោយ​បង្កើត​កម្មវិធី 64-bit។

ជា​មួយ Windows 32-bit អ្នក​អាច​ប្រើប្រាស់ RAM ធំ​បំផុត​តែ 4GB ប៉ុណ្ណោះ។ ចំពោះ Windows 7 64-bit អ្នក​អាច​ដំណើរការ​បាន​លឿន​ជា​មួយ​ទំហំ RAM ធំ​ជាង 4GB ដែល​អាច​ធ្វើ​ការ Upgrade RAM របស់​អ្នក​ឡើង​ដល់ 8GB, 16GB ឬ​លើស​ពី​នេះ។ តាម​ទ្រឹស្ដី Operating System ប្រភេទ 32-bit អាច​ប្រើប្រាស់ RAM បាន​លើស​ពី 4GB ប៉ុន្តែ​ជំនាន់​នៃ Windows Vista និង Windows7 32-bit អាច​ដំណើរការ​សមត្ថភាព RAM បាន​ត្រឹម 3.12GB ប៉ុណ្ណោះ។

ជា​មួយ​នឹង Windows 7 64-bit អ្នក​អាច​ប្រើប្រាស់​ពេញលេញ​ជា​មួយ RAM ដែល​មាន​ទំហំ 4GB ឬ​លើស​ពី​នេះ​ពោល​គឺ​មិន​កំណត់។ ការ​ចែកចាយ​លក់ Windows 7 សព្វ​ថ្ងៃ​ឃើញ​ភាគច្រើន​សុទ្ធតែ​ជា Windows 64-bit ស្រាប់ៗ។ វា​មិន​ខុស​ទាស់​អី​នោះ​ទេ ព្រោះ​ថា​ប្រើ​ប្រព័ន្ធ 64-bit កាន់​តែ​ប្រសើរ ក៏​ប៉ុន្តែ​ចាំបាច់​ឱ្យ​អ្នក​ប្រើប្រាស់​កម្មវិធី 64-bit ដូច​គ្នា ហើយ​មាន 64-bit processor បើ​មិន​ដូច្នោះ​ទេ​ក៏​ពុំ​ទទួល​បាន​ផល​ពី 64-bit Operating System ដែរ។
