You might already have upgraded to ICS 4.0.4 in any how but here with Samsung Kies, you can enjoy with the new upgrading to the latest Ice Cream Sandwich.

I just got today and now being test if they are fine with all apps:

> Device name : GALAXY S2 (GT-I9100)
> Service name : GT-I9100 Software Update
> Service version : PDA:LPF / PHONE:LPB / CSC:LPF (THL)

You can do officially upgrade from Samsung Kies from now.

**Features in this version**

- TouchWiz UI run smoother,
- Improve the notification dropdown,
- Improve the lock ring circle animation,
- Create a contacts link button on the dialer,
- Remove local search,
- Improve browser notification,
- Improve camera and video playback, and
- Add battery percentage to the display setting
