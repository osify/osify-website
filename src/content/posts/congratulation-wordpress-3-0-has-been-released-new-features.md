[WordPress](http://wordpress.org/) (2003-2010) has been released his 3rd generation that has been claimed that it will be the most promising for all new features include:

- New default theme (Twenty Ten) – a flexible theme, that you can give more customize to header, background or even menu
- Merged feature of WordPress MU & WordPress together
- Custom Menu management has been added with [The Awesome Custom Woo Navigation](http://www.woothemes.com/2010/01/the-awesome-custom-woo-navigation/) with drag and drop ordering etc.
- Available also the custom post type feature that we can manage WordPress site as a fully CMS system
- New standard API for theme development
