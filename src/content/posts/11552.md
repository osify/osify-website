II. Validation Annotations

#### **I.          សេចក្តីផ្តើម**

Validation
របស់ user input គឺជាកិច្ចការដ៏ចាំបាច់សម្រាប់
application programmer។ application គួរតែអនុញ្ញាតិតែ
user input ទិន្នន័យដែលត្រឹមត្រូវ ដូច្នេះយើងត្រូវកំណត់ព័ត៌មានដែលអ្នកប្រើប្រាស់បញ្ចូលអោយបានត្រឹមត្រូវ។
នៅក្នុង ASP.NET MVC framework ផ្តល់នូវ built-in
annotation ដែលអាចអោយយើង apply ទៅលើ properties
នៃ Model។ វាធ្វើការ validate នៅពេលបញ្ចូល ហើយបង្ហាញនូវ message ដែលត្រឹមត្រូវទៅកាន់អ្នកប្រើប្រាស់។
