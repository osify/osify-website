Now there is still in trouble when I am now need to switch in a big project group to use Git instead of SVN. Before I made [a research on Git](http://ask.osify.com/qa/302) but it was intended to working alone or with few people on small projects, it won’t get me trouble much.

Now it’s different, I have to work with different teams and location, I met a lot of problem to adapt myself or my team to work with git while before we are doing with SVN.

I’m starting this post here to try to list down all the problem for SVN users need to know or what we want to do as we did before in SVN with Git, here is the tag: [SVN to Git](http://ask.osify.com/qa/tag/svn-to-git).
