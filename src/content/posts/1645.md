#### **I.          សេចក្តីផ្តើម**

នៅក្នុងមេរៀននេះខ្ញុំនឹងបង្ហាញអ្នកទាំងអស់គ្នាអំពីរបៀបបង្កើតម៉ាស៊ីនគិតលេខធម្មតាមួយ
ដែលយើងអាចធ្វើការគណនានូវប្រមាណវិធី ដូចជា បូក ដក គុណ ចែក ជាដើម។ បន្ថែមពីនោះទៀតលោកអ្នកក៏អាចធ្វើការ implement បន្ថែមទាក់ទងទៅនឹងប្រមាណវិធីពីជណិត
(cos, sin, tan, cotan,…) ផងដែរ។
ដើម្បីកាន់តែងាយយល់សូមធ្វើការអនុវត្តន៏ទាំងអស់គ្នាតាមជំហាននីមួយៗដូចខាងក្រោម។

#### **III.        តម្រូវការ**

ដើម្បីអាចបង្កើត Android Project បាន យើងត្រូវមាន៖

- កម្មវិធី
  Android Studio (version
  3.2.1)
- ត្រូវមាន Internet connection
  (ករណីដែលយើងចង់ធ្វើការប្រើប្រាស់ gradle ដើម្បីទាញយក library និងករណីផ្សេងៗចាំបាច់ទៀត)
- Maximum RAM យ៉ាងហោចណាស់ 4GB ឡើង
- CPU គួរតែជាប្រភេទ intel CORE i3 ឡើងទៅ ទើបប្រសើរ
- គួរមាន Hard Disk ប្រភេទ SSD ទើបវាពន្លឿនក្នុងការ run android project បានរលូន
- ត្រូវមាន phone ដែលប្រើប្រាស់ប្រតិបត្តិការ android
- ករណីដែលយើងគ្មាន Phone ដែលប្រើប្រាស់ប្រតិបត្តិការ Android ទេ
  យើងក៏អាចធ្វើការប្រើប្រាស់ Genymotion
  សម្រាប់ធ្វើជា Emulator
