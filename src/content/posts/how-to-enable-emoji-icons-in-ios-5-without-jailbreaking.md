Emoji គឺ​ជា​មុខងារ​ដ៏​ពេញ​និយម​មួយ​សម្រាប់​អ្នក​ប្រើ​ប្រាស់​អ៊ីនធឺណិត​ទាំងនៅ​ក្នុង​វេបសាយ ឬ​ទូរស័ព្ទ​ចល័ត។ ជា​ពិសេស​គឺ​សំរាប់​ទូរស័ព្តដំណើរ​ការ​ដោយ iOS ឬ Android ជា​ដើម ប៉ុន្តែ​ចំពោះ​ iOS វិញ​កាល​ពី​មុន​មិនទាន់​មាន​ការដាក់​បញ្ចូល​មុខ​ងារ​ជា​ស្រេច​នៅ​ឡើយ​ទេ លុះ​ត្រាតែ​អ្នក​ប្រើ​ប្រាស់​ដោន​ឡូដ​កម្មវិធី​បន្ថែមដោយ​ត្រូវ​ Jailbreak ជា​ដើម។

ហេតុ​ដូច្នេះ​ហើយ​ទើប​ ក្រុមហ៊ុន Apple បាន​សំរេច​បន្ថែ​ម​មុខងារ​មួយ​នេះ​រួច​ជា​ស្រេច​នៅ​ក្នុង​ប្រព័ន្ធប្រតិបត្តិការ​ iOS 5 របស់​ខ្លួន​តែ​ម្តង តែ​លោក​អ្នក​ត្រូវ​តែ​ចូល​ទៅ​បើក​វា​សិន​ទើប​អាច​ប្រើ​ប្រាស់បាន។

សូម​លោកអ្នក​ធ្វើ​តាម​ជំហាន​ខា​ង​ក្រោមៈ

1. ចូលទៅក្នុង Setting
2. បើក General -> Keyboard -> International Keyboards
3. ចុច​លើពាក្យ Add New Keyboard
4. បន្ទាប់មក​ចុច​លើ​ពាក្យ​ Emoji ចេញ​ពី​តារាង​របស់ International Keyboards

នោះ​លោកអ្នក​នឹង​អាច​ប្រើ​ប្រាស់​បាន​ដោយ​គ្រាន់​តែ​ចុច​លើ​ប៊ូតុងប្តូរ​ភាសា​របស់ក្តារចុច​រួច​ជា​ស្រេច។Emoji is one of the most favorite functions in website and mobile applications to show user’s feeling with icons. For iOS it has been hacked to use widely, but now since it has been popular Apple ready added this function in iOS 5.

Please follow the step below to enable Emoji keyboard in your iOS 5 devices:

- Launch the Settings app
- Then go to General -> Keyboard -> International Keyboards
- Tap on Add New Keyboard
- And then tap on Emoji from the list of International Keyboards

Then you can use it just by clicking on the language shift key on the keyboards.
