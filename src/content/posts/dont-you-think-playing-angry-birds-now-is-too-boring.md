[![Angry Birds Game](/media/0d/0d3039277f1d-angry-birdsjpg.webp "Angry-BirdsJPG")](/media/0d/0d3039277f1d-angry-birdsjpg.webp)

Angry Birds Game

I feel now the game is for kids, do not match to me but might be you have different feeling from that.

I think if [Rovio Entertainment](http://www.rovio.com/en/our-work/games/view/1/angry-birds) releases more angry birds’ behaviors as:

1. Angry birds walk and fight
2. Angry birds with sword and horse
3. Angry birds go to fight in China, in US or some where
4. More adventures or might be the game expert could found something else than this…

That would be great if so.
Since now, Angry birds’ pictures are every where in any form, on food, on toys or the clothes.

If Angry birds game is keeping the same state of actions, it might be lost interests some days as well.
