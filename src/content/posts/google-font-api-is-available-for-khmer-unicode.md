When I saw a message from [Mr. Danh Hong](http://groups.google.com/groups/profile?enc_user=ogGCHRAAAAAzmzRy_dAdMA-PHKdYiKKC), the one who created most of Khmer Unicode fonts, told us about his new achievement to publish Khmer unicode font via Google Font API, really made me surprised and happy.

[![Sample HTML Google API for Khmer Unicode](/media/8e/8e42aa3ddddc-google-font-api-khmer-unicode-test-osify.webp "google-font-api-khmer-unicode-test-osify")](/media/8e/8e42aa3ddddc-google-font-api-khmer-unicode-test-osify.webp)

Sample HTML Google API for Khmer Unicode

So now welcome to [Google Font API](http://code.google.com/apis/webfonts/docs/getting_started.html) for Khmer Website Designer, it will be more easy to embed Khmer Unicode font via Google API, here is the example:

> <html>
> <head>
>
> <link href=’http://fonts.googleapis.com/css?family=Hanuman’ rel=’stylesheet’ type=’text/css’>
> <style>
> body {
> font-family: ‘Hanuman’, serif;
> font-size: 20px;
> }
> h2 {
> font-family: ‘Hanuman’, serif;
> text-shadow: 4px 4px 4px #006600;
> }
> </style>
> </head>
> <body>
> <h1>Google Font API</h1>
> <h2>អ្នក​ជំនាញ​ស្នើ​ឲ្យ​យក​ជើង ដ មក​ប្រើ​ឡើង​វិញ</h2>
> <p>នៅ​ក្នុង​ពេល​ថ្មី​នេះ មាន​អ្នក​ស្រាវ​ជ្រាវ​មួយ​ចំនួន ចង់​ឲ្យ​មាន​ការ​យក​ជើង ដ មក​ប្រើ​ឡើង​វិញ។ ការ​សំណូមពរ​បែប​នេះ គឺ​ដោយ​លោក​យល់​ថា ការ​យក​ជើង ត មក​ប្រើ​ជំនួស​ជើង ដ នោះ តែង​តែ​នាំ​ឲ្យ​មាន​ការ​យល់​ច្រឡំ នៅ​ក្នុង​ការ​សរសេរ ព្រម​ទាំង​ពិបាក​ចង​ចាំ​ទៀត​ផង។</p>
> </body>
> </html>

Thank [Mr. Danh Hong](http://khmertype.blogspot.com/) for your distribution to Khmer ICT community.
