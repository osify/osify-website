Recently this month, Apple, Adobe, Facebook, Google, HP, Microsoft, Mozilla, Nokia, and Opera have joined the W3C to launch a new website called ‘[Web Platform](http://webplatform.org/)‘ according to the next web.

Of course, it’s kind of an easy way for education purpose if we want to learn about Web technologies today, just go to: [webplatform.org](http://webplatform.org), a central place to start.

If you go to [tutorials](http://docs.webplatform.org/wiki/tutorials) section, you will find all steps to go for each section of Web standard but of course, the document is in alpha, it would update more soon.

WebPlatform covers following topics:

- [HTML5](http://docs.webplatform.org/wiki/html)
- [CSS](http://docs.webplatform.org/wiki/css)
- [Canvas](http://docs.webplatform.org/wiki/canvas)
- [WebGL](http://docs.webplatform.org/wiki/webgl)
- [SVG](http://docs.webplatform.org/wiki/svg)
- [Transforms](http://docs.webplatform.org/wiki/css/transforms)
- [Video](http://docs.webplatform.org/wiki/html/elements/video)
- [Audio](http://docs.webplatform.org/wiki/html/elements/audio)
- [Animations](http://docs.webplatform.org/wiki/css/properties/animations)
- [Media queries](http://docs.webplatform.org/wiki/css/media_queries)
- [IndexedDB](http://docs.webplatform.org/wiki/apis/indexedDB)
- [File API](http://docs.webplatform.org/wiki/apis/file)
- And more…
